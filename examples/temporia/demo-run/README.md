# A real run of the pack (Temporia, 18 November 2026)

Output of an actual run, in the order a user would do it, with real photos.

| Step | Skill | File |
|---|---|---|
| 1 | `studio-ideas` | [1-ideas.md](1-ideas.md): ranked ideas, sources checked, nuance flagged |
| 2 | `studio-create` | [2-package.md](2-package.md): hook, scenes, caption (FR and EN), checklist |
| 3 | `studio-video` | [3-reel/](3-reel/): scene specs (`spec.json` FR, `spec.en.json` EN), rendered `reel.mp4` / `reel.en.mp4`, contact sheet |
| 4 | tracker | [4-log-row.csv](4-log-row.csv): the record written to the log |
| 5 | `studio-analytics` | [5-analytics-report.md](5-analytics-report.md) on [metrics.csv](metrics.csv) (real Instagram numbers via Metricool) |

Notes
- The reel uses three Unsplash photos, credited in [3-reel/photos/README.md](3-reel/photos/README.md). They are not redistributed: download them to re-render.
- The font (Inter ExtraBold, SIL OFL) stands in for the brand font. The reels here are silent; add `"music": "path/to/track.mp3"` to a spec for sound.
- Only one idea was fully source-checked; the others are marked `unverified` on purpose.
